# flores.tools

Cyber Wolf's workshop: small tools for riggers, campers and the curious.

- `npm run dev` — local development
- `npm run verify` — typecheck, lint, tests and build (run before every push)
- `npm run shots` — screenshots of every page at 375/768/1440/2560px in light and dark

Start with `CLAUDE.md`; the brief is in `docs/BRIEF.md`.

Fonts: Mona Sans and JetBrains Mono, both under the SIL Open Font License (see `src/fonts/`).
